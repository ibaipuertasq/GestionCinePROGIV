DESCRIPCION DEL PROYECTO

Este proyecto es un sistema cliente-servidor para la gestión de un cine, desarrollado en C (servidor) y C++ (cliente). Permite a los usuarios registrarse, iniciar sesión, ver la cartelera, comprar entradas, consultar sus compras y, para administradores, gestionar películas, salas, sesiones y usuarios. Toda la información se almacena de forma persistente en una base de datos SQLite. El sistema incluye autenticación, control de permisos y una arquitectura orientada a objetos en el cliente.

COMPILAR Y EJECUTAR
    Compilar
        .\compile.bat
    Ejecutar (por separado)
        .\servidor.exe
        .\cliente.exe
